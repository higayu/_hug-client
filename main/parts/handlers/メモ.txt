# SQLite 同期処理メモ

## 目的

Electron の renderer 側で保持している Redux の `databaseState` を、main 側の `sqliteHandler.js` に渡し、SQLite に同期する。

同期対象は、`databaseState` のキー名と SQLite 側の実テーブル名が一致するもの。

---

## 同期の基本方針

固定の `syncOrder` は使わない。

SQLite 側から実テーブル一覧を取得し、`databaseState` に同じキーがあり、値が配列になっているものだけを同期対象にする。

```txt
SQLite 実テーブル名
      ↓
databaseState に同じキーがあるか確認
      ↓
一致するテーブルだけ DELETE
      ↓
databaseState の配列データを INSERT
```

---

## VIEW は同期しない

`sqlite_master` から取得する時に `type = 'table'` のみ対象にする。

そのため以下のような VIEW は同期対象外になる。

```txt
child_records_v
children_facility_all2_v
experience_children_v
waiting_children_v
```

VIEW は元テーブルから参照するものなので、INSERT / DELETE の対象にしない。

---

## SQLite 内部テーブルも同期しない

以下は SQLite 内部管理テーブルなので同期しない。

```txt
sqlite_sequence
```

SQL 側で `name NOT LIKE 'sqlite_%'` を指定して除外する。

---

## sqliteHandler.js に追加する helper

```js
async function getSqliteTables(db) {
  const rows = await allSql(
    db,
    `
      SELECT name
      FROM sqlite_master
      WHERE type = 'table'
        AND name NOT LIKE 'sqlite_%'
      ORDER BY name;
    `
  );

  return rows.map((row) => row.name);
}

function getSyncTargetTables(sqliteTables, databaseState) {
  return sqliteTables.filter((tableName) => {
    if (!Object.prototype.hasOwnProperty.call(databaseState, tableName)) {
      return false;
    }

    return Array.isArray(databaseState[tableName]);
  });
}
```

## sqlite:database:sync の処理方針

```js
safeHandle(ipcMain, "sqlite:database:sync", async (_, databaseState) => {
  const db = connect();

  try {
    if (!databaseState || typeof databaseState !== "object") {
      throw new Error("databaseState が不正です");
    }

    console.log("🔄 SQLite databaseState 同期開始");

    const sqliteTables = await getSqliteTables(db);
    const syncTables = getSyncTargetTables(sqliteTables, databaseState);

    console.log("📚 SQLite 実テーブル:", sqliteTables);
    console.log("📦 databaseState keys:", Object.keys(databaseState));
    console.log("✅ 同期対象テーブル:", syncTables);

    await runSql(db, "PRAGMA foreign_keys = OFF;");
    await runSql(db, "BEGIN TRANSACTION;");

    for (const tableName of [...syncTables].reverse()) {
      await runSql(db, `DELETE FROM "${tableName}";`);
    }

    const results = [];

    for (const tableName of syncTables) {
      const rows = databaseState[tableName];
      const result = await insertRows(db, tableName, rows);
      results.push(result);
    }

    await runSql(db, "COMMIT;");
    await runSql(db, "PRAGMA foreign_keys = ON;");

    return {
      success: true,
      syncedTables: syncTables,
      results,
    };
  } catch (err) {
    try {
      await runSql(db, "ROLLBACK;");
    } catch (_) {}

    try {
      await runSql(db, "PRAGMA foreign_keys = ON;");
    } catch (_) {}

    throw err;
  } finally {
    await closeDb(db);
  }
});
```

## renderer 側で必要なこと

同期ボタンで `databaseState` 全体を main に渡す。

```js
const databaseState = useSelector((state) => state.database)

const result = await window.electronAPI.syncDatabaseStateToSqlite(databaseState)
```

同期前に件数ログを出すと確認しやすい。

```js
console.log(
  "📦 databaseState 件数:",
  Object.fromEntries(
    Object.entries(databaseState)
      .filter(([, value]) => Array.isArray(value))
      .map(([key, value]) => [key, value.length])
  )
);
```

## preload.js に必要な追加

```js
syncDatabaseStateToSqlite: (databaseState) =>
  ipcRenderer.invoke("sqlite:database:sync", databaseState),
```

---

## 注意点

この同期方式は、対象テーブルを一度空にしてから入れ直す。

```txt
DELETE
↓
INSERT
```

そのため、SQLite にしかないローカルデータは消える。

`users` や `refresh_tokens` も `databaseState` に存在すれば同期される。
認証情報をローカル SQLite に保存したくない場合は除外処理を入れる。
